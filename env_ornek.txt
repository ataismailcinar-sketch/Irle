# --- Beyin modu ------------------------------------------------------
#  hibrit : internet varsa Groq (ücretsiz bulut), yoksa Ollama (yerel)
#  bulut  : sadece Groq
#  yerel  : sadece Ollama — tamamen çevrimdışı (köy modu)
#  kapali : dil modeli yok, eski kural motoru

# --- Groq (ücretsiz, kredi kartı istemez) ----------------------------
#  1) https://console.groq.com adresinde Google hesabınla giriş yap
#  2) "API Keys" → "Create API Key" → anahtarı aşağıya yapıştır

# --- Ollama (yerel, çevrimdışı) --------------------------------------
#  1) https://ollama.com → Windows için indir, kur
#  2) Terminalde:  ollama pull qwen2.5:7b
#     Yavaş gelirse daha küçük model:  ollama pull qwen2.5:3b

# --- Ses (TTS) -------------------------------------------------------
#  auto    : data/sesler'de Türkçe Piper sesi varsa onu, yoksa Windows sesini kullan
#  piper / pyttsx3 : zorla o motor
IRLE_SES_MOTORU=auto

#  hibrit : Groq Whisper (internet, ücretsiz) → yerel Whisper → Google

#  groq / google : sadece o servis (+ Google yedek)
